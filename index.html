Set up a Bobble

Put the Bobble software on a new display from this page, then connect it to your Mac. Version ….

  1. Plug the Bobble into this computer

    Use a USB-C cable that carries data, not just power. Use Chrome, Edge or Arc on a computer: Safari and phones can't do this step.

  2. Install the software

    Choose the Bobble's port (usually "USB JTAG/serial debug unit"). For a new Bobble, or one changing hands, say yes to erasing it.

    This browser can't reach USB devices. Open this page in Chrome or Edge on a computer. This page needs to be opened over https.

    It takes about a minute. The Bobble restarts by itself when it's done.

  3. Get it online

    Tap the bubble on the Bobble's screen and scan the code with your phone, then pick your Wi-Fi.

  4. Connect your Mac

    Get the Bobble app, open it (the first time: System Settings › Privacy & Security › Open Anyway), choose Pair with Display… from its menu, and type the code your Bobble shows.

    Download the Mac app
After this, the Mac app keeps itself and the Bobble up to date. No browser handy? With the Bobble plugged in, run ./flash_new.sh from the repo's amoled_demo folder.
